Third-party notices and attribution status
=========================================

The project is Copyright 2026 Matt Curfman, licensed under Apache-2.0; see LICENSE.
That license does not relicense third-party components.

Binary distributions include THIRD_PARTY_LICENSES.txt generated by pinned
cargo-about 0.8.1 from resolved Cargo dependencies using packaging/about.toml
and packaging/about.hbs. It includes license texts and version-specific source
download links (including MPL-2.0 sources). The generated file is included in
archives and /usr/share/doc/vps in Debian packages, and published separately
alongside each platform's release downloads. Cargo.lock records the source
dependency inventory; no generated file is represented here as a completed audit.

Before release the maintainer must review all linked/build-generated components,
upstream copyright and NOTICE content, and any source-delivery obligations.
cargo-about excludes build and development dependencies from its notice output;
verify that no generated code or bundled data from those dependencies is shipped
without its required attribution. Apache NOTICE content is distinct from this
general listing and must be preserved where applicable. ORT/ScanCode piloting,
native/runtime inventory reconciliation, and logo.jpg provenance review remain
open. Unknown or conflicting terms must be resolved before distribution.

The embedded cloud-init template downloads Ubuntu packages, Docker, Node.js and
Codex onto operator-managed workers. Those components are not bundled binaries
in the project's release packages. Operators must review their upstream terms
and provenance separately. No model weights are shipped by this repository.
